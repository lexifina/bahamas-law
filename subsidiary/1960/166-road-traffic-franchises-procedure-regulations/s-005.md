# 5.
Every application for a tour car franchise shall contain, inter alia, the following particulars -
(a) the registered number or the classes and description of all vehicles to be used;
(b) the registered number or the classes and description of all vehicles in (a) to be used for carriage of passengers on prearranged transfers;
(c) the days or occasions on which vehicles will be used and the number of vehicles to be used on such days or occasions; and
(d) the number and positions of picking up and setting down points.
