# 29. General
The EMS including SBGS, where applicable, refers to all hardware and software utilised for communication between slot machines, terminals and electronic table games and the EMS file server for the storage of gaming-related information and includes the following equipment -
(a) cabling from all gaming devices to the file servers;
(b) communication Interfaces;
(c) front end processors;
(d) floor servers;
(e) gaming device managers;
(f) patch panels;
(g) table game information systems;
(h) jackpot controllers and engines; and
(i) file servers.
