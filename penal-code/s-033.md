# 33. Definition of "offences against females or children"
The following provisions apply to every offence punishable under Title xi. or Title xix. of this Code and any offence, committed against a child under sixteen years of age, comprised in Title x. or Title xviii. or Title xx. of this Code including the offences mentioned in section 110 (5)of the Child Protection Act; and all such offences are in sections 34 to 41 of this Code referred to as "any of the said offences against females or children".
