# 496. References to corresponding offences under previous and existing law
(1) A reference in any other Act to any offence under the law as it existed before the commencement of this Code shall be deemed to be a reference to any corresponding offence under this Code.
(2) A reference in this Code to any offence under this Code shall be deemed to be a reference to any corresponding offence under the law as it existed before the commencement of this Code.
