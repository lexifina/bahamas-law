# 134. Magistrate to deal with the deposition like any other deposition
If such deposition relates to an offence, the preliminary inquiry into which has ended, the magistrate taking it shall send it to the Registrar to be placed with the other depositions taken in the case, and if it relates to an offence with which some person has been charged, and as to which a preliminary inquiry is in progress, the magistrate shall deal with it like any other deposition taken in the matter under preliminary inquiry; but such person as aforesaid so making a deposition shall not be called upon to enter into a recognisance to give evidence at the trial of the accused.
